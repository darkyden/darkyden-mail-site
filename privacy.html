Privacy Policy

Effective date: October 24, 2026

Darkyden Mail is a personal, locally run desktop integration for displaying Gmail mailbox status in the dwm window manager. This policy describes how the application accesses and uses Google user data.

Information accessed

When the user explicitly authorizes a Gmail account through Google OAuth, the application requests the Gmail read-only scope (https://www.googleapis.com/auth/gmail.readonly). It may read message metadata and content necessary to obtain unread-message counts and message subjects for display in the desktop status bar. The permission is read-only: the application does not send, delete, or modify email.

How the information is used

Gmail information is used solely to generate a local mailbox-status display and to help the user open the appropriate Gmail inbox in their browser. It is not used for advertising, profiling, or model training.

Storage and retention

OAuth tokens are stored locally on the user's computer for authorized API access. A local status cache may temporarily contain unread counts and message subject text. No Gmail messages or OAuth tokens are uploaded by the application to this website or to a Darkyden-operated server. Locally stored tokens and cached data remain until removed by the user or replaced during normal operation. Users can remove the local credentials and status cache to delete those local copies.

Sharing and disclosure

Darkyden Mail does not sell, rent, or share Google user data with advertisers, data brokers, or other third parties. Gmail API requests are made directly to Google's services from the user's device. Opening an inbox takes the user to Gmail in their browser, subject to Google's own privacy practices.

Security

The application is intended to run locally under the user's operating-system account. Users are responsible for protecting their local credentials and computer access. OAuth tokens and client secrets must not be committed to public source repositories.

Revoking access and deleting data

Users can revoke Darkyden Mail's Google account access through Google Account connections. They can also delete locally stored OAuth token files and the local status cache. Revocation stops future authorized Gmail API access; it does not automatically delete local files.

Website

This informational website does not include analytics scripts, advertising trackers, or external JavaScript. It is hosted through GitHub Pages; GitHub may process technical access data according to its own policies.

Changes and contact

This policy may be updated when the application's behavior changes. Questions or privacy requests can be sent to darkyden@gmail.com.
