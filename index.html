Darkyden Mail

A personal Gmail status integration for the dwm window manager on Gentoo Linux.

What it does

Darkyden Mail uses the Gmail API with read-only authorization to retrieve mailbox information such as unread counts and message subjects. It displays a compact status in the local dwm bar and lets the user open the corresponding Gmail inbox in their browser.

Designed to stay local

  • Personal desktop utility, not a hosted email service.
  • OAuth authorization and Gmail API requests run on the user's own computer.
  • OAuth credentials and tokens are kept locally and are not published on this website.
  • This website contains no analytics scripts, advertising trackers, or external JavaScript.
